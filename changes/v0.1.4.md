  fork 不可用路径）；② 子 agent **默认不继承**全局上下文文件（`~/.rpi/agent/AGENTS.md`，对齐上游 #1560）——
  插件为 child 注入 `RPI_NO_GLOBAL_CONTEXT=1`，宿主仅跳过全局段（项目/仓库上下文链保留），普通 rpi 会话行为
  逐字节不变；**迁移指引**：需要子代理继承的全局规则放入项目 `AGENTS.md` 或 agent 定义 `systemPrompt`
  （本版不新增 opt-in 配置键，`inheritGlobalContext` 留作后续增量）。
- **subagents steer 门与投递状态**（TE19，R7.1.8.1–.3 / #1980/#1976/#1983/#1965）：单 child 后台运行被未答复的
  supervisor 问题阻塞时，`steer` 不再「假投递」——返回 `need_decision` 指引并携带 request id（`subagent_supervisor

  `childId`（`step:<index>` 或 child run id）停单个 child，拒绝时不扩大为整 run 停止。

- **subagents 模型面与配置面 v0.66 键**（TE19，R7.1.10/R7.1.11 / #1397/#1393/#1318/#1439/#1328/#1305/#1587/
