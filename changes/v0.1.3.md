# v0.1.3(2026-09-03)

本版本主线：**性能与并发治理**——全仓审计驱动的 7 项任务（V13-01…07）+
两支先行 PR 收口（`fix/stream-idle-timeout-write-perf` / `feat/statusline-
live-token-count`）。定性原则：移植退化对齐上游形态、移植引入的并发缺陷
补 Rust 并发化欠账、自创节流层只在 FFI 边界成本处加且终态/末帧语义不变。
零新 ABI（唯一宿主依赖 `ctx.sessionFile` 随 ADR-0022 已落地）、零新 ADR。

## 第一方插件(新 / 增强)

- **statusline 实时 token 计数**（V13-10，先行 PR）：`statusLine.liveTokens`
  键开启流式期间 1Hz 级脚本重跑；stdin 新增 `rpi.live_output` 纯测量块
  （字符累计/增量窗口/elapsed/精确 output token），换算留在用户脚本。
  随行宿主两处：八事件载荷转发 parity 补齐、`ctx.sessionFile` additive
  host-call（ADR-0022）——双开同 cwd 串数据治本。
- **rpi-ext-subagents 父会话权威定位**（V13-02）：`parent_session` 优先
  `ctx.sessionFile`（权威值恒为新会话），目录启发式降级为兜底并加固
  （mtime 下界 + `<ISO ts>_<uuidv7>` stem 形状过滤，排除 `fork*` 自污染）；
  四个消费点改用权威 session id（关闭 TE-D16）。

## 修复

- **edit 工具误报 `Could not find edits[N]` 但编辑实际成功**（V13-11，v0.1.3
  追补，rpi#18）：预览竞态（UI 排空滞后于 agent 写盘时，预览对已编辑
  文件找 `oldText` 必失败）叠加移植回归——上游 `renderResult` 回填
  `details.diff` 后就地重建 call 组件（edit.ts:416-424），rpi 的
  `update_display` 先构建 call 组件后执行 result 回填，同帧太迟且此后
  无重建，红色错误永久钉在滚动记录。修复：`ToolExecutionComponent
  ::update_display` 两条 shell 路径改为 result 组件先构建（回填状态先
  落地）、call 组件后构建（读到回填后预览），`add_child` 顺序不变；
  竞态伤害降为与上游一致的「一闪而过」（竞态本身上游固有，不修）。
- **`rpi update --extensions` 只升级一个插件**（未跟踪安装发现，v0.1.3 追补）：
  update/list 只遍历 `settings.json` 的 `packages` 条目，而扩展加载器加载
  extensions 安装根目录下**所有**带 manifest 的目录——早期版本安装 / 手工
  复制的未跟踪插件被 update 静默跳过，多插件场景即表现为“只升级一个”。
  update 现与加载器发现对齐（loader parity）：全量更新把未跟踪安装按
  identity 去重后并入批次（`.rpi-install-source` marker 或 manifest 名重新
  解析，不回写 settings；`.tmp-*`/`.old-*` 残留目录跳过），`rpi update
  <name>` 也可按 identity 命中未跟踪安装；`rpi list` 以 `(untracked)` 标注。
  随行两处健壮性：registry 批量更新单个失败不再 `?` 短路其余（首个错误
  按源序在批末返回，逐条错误即时经进度回调输出 stderr）；未跟踪安装且
  registry 未收录（404）降级为跳过提示——本地开发目录不拖垮 update，
  跟踪源 404 仍为硬错误。
- **流式请求总超时误杀活跃流**（V13-08，先行）：`httpIdleTimeoutMs` 曾
  误映射到 reqwest 总 deadline，长推理 4 分 59 秒被掐断——改三段式超时
  （connect / headers / body 块间静默 idle，每 chunk 重置）；9 个 SSE
  adapter 全覆盖，codex 绝对 deadline 与 openrouter_images 一次性请求
  两处有意例外。
- **write 大文件流式渲染 O(n²)**（V13-09，先行）：syntect 整块重高亮与
  全量重建随行数平方级退化——稳定前缀窗口跳重算 + 可见内容指纹跳重建 +
  repair_json 惰性化 + agent_loop 深拷贝 3→2（勘误：首发误记 3→1——state 拷贝
  已除，context 尾更新为上游 parity 必需、事件载荷需独占所有权，各留 1 次）；
  实测 400 行流式 2250ms →
  245ms（9.2×），完成后重渲染 46.8ms → 6µs。
- **扩展 UI 换装撕帧**（V13-05，并发正确性）：widget 换装拆两段临界区，
  渲染窗口期闪缺失帧；selector 换装先 hide 后 show 闪裸 editor + 焦点
  错位——mount_widget 单锁原子化（跨容器 add-then-remove）+ selector
  `swap_editor_region` 单锁 clear+add+set_focus。
- **流式渲染热路径拷贝/重建**（V13-06）：`MessageUpdate` 队列连续段折叠
  保尾（单次 drain K 条 delta → 恰好 1 次 `update_content`）+ `update_content`
  收引用消除调用侧深拷贝；最终帧逐行一致，重建次数受渲染帧率封顶。
