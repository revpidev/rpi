# v0.1.5-rc.1 (2026-09-27)

**Pre-release (pre-release channel)**: candidate for the `0.1.5` stable release, published ahead of it for verification. Content matches `changes/v0.1.5.md` (the upstream-parity v0.86.1 main line + the plugin line + the three rpi-native fixes); at stable-release time this file's entries fold into `v0.1.5.md`. Install: existing rpi users run `rpi update --rc` (or `rpi update --all --rc` to also update the six lockstep extensions to `0.1.5-rc.1`); install.sh does not serve RCs (`releases/latest` stays stable). The new first-party plugin installs from the RC channel with `rpi install rpiv-todo --rc` (it has no stable release yet — without `--rc` the bare name resolves to nothing).

## New in this RC (first release of the v0.1.5 window)

- **Sixth first-party plugin: `rpiv-todo`** (TE34–36) — a live task-list overlay the model keeps current with one tool call, rebuilt from the session branch so it survives compaction and `/reload`; registry key `rpiv-todo`, `minHostVersion` = this lockstep version, native carrier only. First release rides the RC channel.
- **Upstream parity to v0.86.1** (V15-01…15, ADR-0029/0031): the behavioral gold standard moves to `19451accd` (v0.86.1+1); per-domain highlights in `changes/v0.1.5.md` — **[BREAKING]** mid-conversation system messages (`TranscriptContext`), per-model compaction budgets, prompt cache warming, progressive session discovery, the Meta provider + Muse subscription OAuth, the v0.86.1 model catalog (41 providers / 1443 models), verified clipboard writes with headless OSC 52 fallback, and the linear streaming-render fix (rpi#53).
- **Plugin rebases**: subagents v0.70.0 (**[BREAKING]** — `fallbackModels` removed; a retryable failure no longer switches models mid-launch), mcp-adapter v2.34.0+ (encrypted-file OAuth credential store, CIMD, `/mcp edit`, `directTools: "search"`), ask-user-question transcript rendering (rpi#52).
- **rpi-native fixes**: #52 / #53 / #54 (SSE idle timeout now unlimited by default — restore the old behavior with `httpIdleTimeoutMs: 300000`).

## Verification requests (the point of the RC)

- Self-update path on all six targets (`rpi update --rc` download + sha256 verification + atomic replacement; Windows gets manual-replacement instructions).
- `rpi update --extensions --rc`: the **six** lockstep extensions going `0.1.4` → `0.1.5-rc.1` — including the **first-ever release of `rpiv-todo`** (`rpi install rpiv-todo --rc` for a fresh install); without `--rc` the five previously-shipped extensions stay at 0.1.4 and `rpiv-todo` is not resolvable (the stable channel filters prereleases).
- The upstream-parity v0.86.1 behavioral surface and the three rpi-native fixes (#52/#53/#54) — the task list is in `changes/v0.1.5.md`.

Known boundary: the RC endpoint (`https://revpi.dev/api/latest-rc-version.json`) goes live once the Release assets are in place; self-hosted mirrors must provide the file in the same directory.
