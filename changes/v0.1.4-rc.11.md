# v0.1.4-rc.11(2026-09-12)

**预发布(pre-release channel)**:`0.1.4` 正式版候选第十一轮。本轮 = **发布前全面审查修复全项闭环**(P0×1 / P1×7 / P2×13 + 文档发布一致性 + CI 质量门禁;P2-1 一项登记偏离待办)。基线内容与 `changes/v0.1.4.md` 一致;正式版发布时各 rc 文件条目并入 `v0.1.4.md`。安装/升级:已装 rpi 用户 `rpi update --rc`(或 `rpi update --all --rc` 同步扩展到 `0.1.4-rc.11`);官方脚本强装 `RPI_GITHUB_API_URL=https://api.github.com/repos/revpidev/rpi/releases/tags/v0.1.4-rc.11`。

## 相对 rc.10 的增量

- **P0 panic hook 接线**:交互模式与首次设置窗口此前从未安装 panic hook——任一 panic 会把终端留在 raw mode/备用屏,需手工 `stty sane && reset`(违反 coding-standards §8.5 硬性要求)。现于 `TuiHandle` 构造后安装面向句柄的恢复 hook,覆盖主屏与全屏 alt-screen 双变体(非阻塞 try_stop + 固定恢复序列兜底),任一 panic 后终端必恢复。
- **P1 修复族**:① `read` 工具负/极端 `limit` 触发切片 panic(模型可控参数)——回归 JS slice 空选区语义;② Windows 上 bash 工具超时/取消完全失效(kill 为空实现且 wait 不收敛)——落地 System32 `taskkill /F /T /PID` + kill 后 5s 兜底宽限;③ subagents `syntheticPaths` 未做归一化校验,可删除 worktree 之外目录——补齐上游四类校验;④ 并行工具批 panic 时 `tool_execution_end` 缺失(start/end 配对破裂、`pending_tool_calls` 残留)——JoinError 槽位补发;⑤ mcp adapter `Ready` 发布与 `on_ready`(含审批恢复)之间的可观测窗口——hooks_complete 门消除(全量门禁抖动根因闭合);⑥ 八个 SSE adapter 体读阶段不响应取消(需等下一 chunk 或 5 分钟空闲超时)——改为与取消信号 race;⑦ 首次设置流程早退路径泄漏 raw mode 并污染 `was_raw`——错误路径先 stop UI。
- **P2 加固族**:wasm guest 内存 128MiB 上限(fuel 只限 CPU 不限内存);SSE 单行 1MiB / Bedrock 帧 16MiB 上限 fail-fast;SSE 空 `data` 事件容错;`auth.json` 原子写;会话 `parentId` 环防护;smart-fetch 响应体 32MiB 上限(登记偏离);compaction `session_id` 上游语义;`--rc` 无预发布索引降级为"已是最新";扩展名单组件校验;`parity_runner` 唯一命名;批次临时目录卫生等(markdown 变换渲染锁一项登记偏离待办,全项见 `changes/v0.1.4.md` 审查修复节)。
- **文档/发布一致性**:README 38→40 providers;CHANGELOG.md 同步三条增补线与审查修复节(该文件编译进二进制驱动 `/changelog`);mcp-adapter manifest 描述 v2.32.1;官网 changelog 同步;RELEASING.md 补 changelog 同步步骤。
- **CI 质量门禁**:新增 fmt/clippy/test 工作流(main push 与 PR 触发;此前仅 tag 构建,门禁依赖人工)。

## 验证请求(rc.11 重点)

- **panic 后终端恢复**(P0):正常使用中如遇任何 panic(或人为构造),终端应立即恢复可用状态——不再需要 `stty sane && reset`。
- **Windows 用户重点**:bash 工具的 `timeout` 参数与 Esc 取消现在应正常生效(此前会挂住整个工具调用)。
- **取消长流式响应**:模型流式输出期间取消,应立即停止(不再等最长 5 分钟空闲超时)。
- **`rpi update --all --rc`**:rc 毕业窗口内对已全 stable 的扩展索引不再硬报错(降级为已是最新提示)。
- 其余验证面同 rc.10(对话框高度)与 rc.8(对话框高度初轮)。
