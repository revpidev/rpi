# v0.1.5-rc.5 (2026-09-28)

**Pre-release (pre-release channel)**: candidate for the `0.1.5` stable release. Content = `v0.1.5-rc.4` plus the batch below; at stable-release time this file's entries fold into `v0.1.5.md`. Upgrade: `rpi update --rc` (or `rpi update --all --rc` to also move the six lockstep extensions to `0.1.5-rc.5`).

A small batch: one real-use TUI fix (the todo panel glued to the input box), the built-in model catalog refreshed to the latest upstream-generated snapshot, and the common-provider template generator repaired.

## Fixed in this RC

- **The todo overlay breathes again — blank widget lines render as rows** (found in real use after rc.4): the `rpiv-todo` panel ended flush against the editor's top border, even though the plugin deliberately ends its line set with an empty spacer row (`withTrailingSpacer` — "so the overlay isn't flush against the editor box"). The interactive widget dock mounted every `setWidget` line as a `Text` component, and `Text` renders whitespace-only input as **zero lines** (upstream's "Don't render anything if there's no actual text"), so the spacer row was silently swallowed. Blank lines in a widget's line set now mount as `Spacer(1)` — every array entry renders exactly one row, and the panel keeps its blank gap above the input box. Upstream pi drops the row the same way (the rpiv-todo spacer never rendered there either); rpi honors the extension-facing intent. Pinned by `w4_blank_widget_lines_render_as_rows` (red on the old code: 2 rendered rows instead of 3).
- **Built-in model catalog refreshed to the 2026-09-23 snapshot** (same pinned `19451accd` generator rules; 41 catalogs / **1502** models, +59 net over the 2026-09-20 snapshot vendored at rc.3): new faces — `claude-opus-5-5` (anthropic direct + bedrock regions + copilot/opencode/openrouter/vercel/radius), `gpt-6-luna` & `gpt-6-sol` (openai + azure + copilot + openrouter incl. `-pro` and batch variants + vercel incl. `-fast` + radius), `grok-4.7` (xai + copilot + opencode(-go) + vercel), the `mimo-v2.6` family flash/pro/pro-ultraspeed (xiaomi + the three token-plan regions), `tencent/Hy4-preview` (huggingface), and openrouter +20/−12 (cohere `command-a-plus`, `nex-n2.5-pro`, batch-variant cleanup); nvidia drops `deepseek-v4-flash-0731`. Catalog pins synced across the test suites (total/generatedAt/radius baseline 30/per-provider counts).
- **`generate-common-models-json.py` handles the multi-group openrouter catalog** (broken since the openrouter catalog split into `openai-completions` + an anthropic-messages Claude-only group): following the script's xai precedent the openrouter entry pins `chosen_api = "openai-completions"` (the general catalog, `/v1` — what the template already carried), and `examples/models.json` is regenerated against the new snapshot (12 providers / 482 models).
