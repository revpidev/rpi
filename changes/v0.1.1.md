# v0.1.1(2026-08-16)

本版本三大主线：对齐上游 Pi v0.84.1(T17–T32,parity freeze)、三个常用 Pi 插件的
Rust 移植落地（TE01–TE11)、扩展分发与安装链路打通（registry / 官网索引 / CI 打包）。

## 扩展分发与安装(新)

- **`rpi install <name>[@<range>]`**:registry 渠道。裸名解析 revpi.dev 索引
  (`/api/extensions/<name>.json`),semver 选版(支持精确 / `^` / `~`,缺省最新),
  安装前预检 `rpiAbi` 与 `minHostVersion` 兼容性;下载 GitHub 直连优先、官网边缘
  代理回退,sha256 以官网索引记录为准校验,不匹配立即中止不换源。
- **`rpi install github:<owner>/<repo>[@<tag>]`**:直指 GitHub Release artifact
  渠道(未收录/私有插件用),完整性校验退化为 Release 自带 `.sha256` sidecar,
  安装输出明示完整性级别差异。
- **`.rpix` 打包格式**:gzip tar,根目录含 `rpi-extension.json` + 载体 +
  `SHA256SUMS`;安装时逐文件校验、name/version 一致性校验、临时目录原子替换到
  `~/.rpi/agent/extensions/<name>/`(或 `-l` 项目级 `.rpi/extensions/`)。
- **信任提示**:install/update 展示 author 与 capabilities 全表;L0 原生插件
  (无沙箱、全 OS 权限)显著警告,交互模式需确认或 `--yes`。
- `remove` / `list` / `update` 全链路支持新渠道;`RPI_REGISTRY_URL` 可注入
  registry 镜像/测试地址,`off` 整体禁用。
- **第一方插件随主版本发布**:CI 在 6 目标 matrix 上将 `rpi-ext-subagents` /
  `rpi-ext-mcp-adapter` / `rpi-ext-smart-fetch` 各自打成
  `<name>-<version>-<target>.rpix`,与本体同一 GitHub Release 发布,版本锁步;
  官网索引自动收录并标「官方插件」。
- revpi.dev 新增:`/api/extensions/` 索引 API(静态生成)、
  `/extensions/download/` 下载代理(白名单 + 边缘回源)、插件目录页
  (extensions.html,展示 capabilities 与 L0 信任文案)。

## 第一方插件移植(TE01–TE11)

- **rpi-ext-mcp-adapter**(移植 pi-mcp-adapter v2.24.0):MCP 客户端适配器——
  配置三源合并、stdio/SSE/HTTP 三传输、OAuth 全流程(PKCE fail-closed)、
  代理与 direct 工具注册、懒连接生命周期与会话恢复、状态行接线与工具结果折叠
  渲染;parity 对拍证据链(scripts/mcp-parity)。
- **rpi-ext-subagents**(移植 pi-subagents v0.48.0):`subagent` 工具结构化委派——
  六内置 agents 与四级发现/别名/agentOverrides、fresh/fork、组合编排与后台异步
  runner、worktree 隔离、acceptance gates 与运行预算、supervisor 协调通道、
  流式进度/消息渲染与 TUI 可视化(TE11)、artifacts 三模式与节流清理、
  `/run` `/subagents` `/subagents-doctor`;对拍 harness 全 MATCH + E2E 双轨。
- **rpi-ext-smart-fetch**(移植 agent-smart-fetch v0.3.17):`web_fetch` 全管线——
  batch 并发、meta refresh / alternate 回退、流式下载、进度事件流与 spinner、
  组件树渲染、settings 接线。
- **扩展 ABI 补齐**(TE01,ADR-0015):`unregisterTool` / `toolUpdate` 双载体,
  registerTool capability 拒绝、own-registry 隔离、wasm 每扩展独立 Store;
  完全 additive,`RPI_ABI_VERSION` 保持 1。

## 行为变更

- **移除 npm/pnpm/yarn/bun 自更新分支**(ADR-0011 修订决策 7,偏离 D-055):
  GitHub Releases 二进制为唯一发行渠道,四个包管理器分支为不可达死代码,移除;
  `update --self` 恒走二进制真自更新。`npm:` 扩展包安装渠道不受影响。
- **CI 构建改为仅 tag 触发**:`main` / `0.*` 分支推送不再自动构建,
  `workflow_dispatch` 保留手动触发。

## 修复

- 多 native 插件共载失败——abi_stable 按类型 memoize 的模块加载根因,改 per-path
  加载。
- SSE 行上限对齐 SDK ReadBuffer 10MiB——审查波引入的 8KiB 上限误吞大行响应
  (补 512KiB 跨块回归测试)。
- 全屏热切换后输入失效、/settings 卡死、/settings 切换 tui-mode 卡死。
- file_processor 测试 TempDir 命名竞态;bash 结果截断警告行按终端宽度换行。
