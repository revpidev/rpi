# v0.1.5-rc.2 (2026-09-27)

**Pre-release (pre-release channel)**: candidate for the `0.1.5` stable release. Content = `v0.1.5-rc.1` plus the fix below; at stable-release time this file's entries fold into `v0.1.5.md`. Upgrade: `rpi update --rc` (or `rpi update --all --rc` to also move the six lockstep extensions to `0.1.5-rc.2`).

## Fixed in this RC

- **The rpiv-todo overlay never appeared in a real interactive session** (rc.1 field verification; the tool itself worked — only the panel was missing): the interactive mode attached the extension UI bridge **after** `bind_extensions`, so the `session_start` event dispatched with no UI attached and the plugin's overlay foreground claim silently never ran. Upstream binds the two atomically (`bindExtensions({ uiContext, mode: "tui" })`); rpi now attaches the bridge first at both call sites — mode boot **and** every session-switch rebind (`/new` / `/resume` / `/clone` / `/fork` / `/import`). A real-mode boot e2e pins the ordering (it fails against the inverted order).
