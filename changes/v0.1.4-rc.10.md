# v0.1.4-rc.10(2026-09-12)

**预发布(pre-release channel)**:`0.1.4` 正式版候选第十轮。本轮 = **ask-user-question 对话框高度稳定二轮修复**(rc.9 实机验证报告:① 高亮移到 "Type something." 行时总高跳变;② Submit 页页脚提示行悬空、距终端底边很远)。基线内容与 `changes/v0.1.4.md` 一致;正式版发布时各 rc 文件条目并入 `v0.1.4.md`。安装/升级:已装 rpi 用户 `rpi update --rc`(或 `rpi update --all --rc` 同步扩展到 `0.1.4-rc.10`);官方脚本强装 `RPI_GITHUB_API_URL=https://api.github.com/repos/revpidev/rpi/releases/tags/v0.1.4-rc.10`。

## 相对 rc.9 的增量

- **对话框高度稳定二轮修复**:① 聚焦 "Type something." 行进入输入模式会隐藏 markdown 预览 pane,而 worst-case 高度探测沿用了当前帧的 input-mode,垫行基准一并塌缩——焦点在输入行与选项行之间移动时总高来回跳(带预览题目实测 21→13 行)。探测改为恒按非输入模式计算(输入模式 body 可证 ≤ 预览模式 body),垫行吸收差值,总高恒定。② 残差垫行原追加在页脚提示行之后(上游将其藏在自身底部边框下方,视觉不可见;rpi 无边框且 overlay 底部锚定,提示行被空行顶离终端底边,Submit 页实测悬空 13 行)——垫行改为插在页脚块之前:总高不变,提示行恒为对话框末行、贴终端底缘;Submit 页 picker 焦点/备注光标随垫行插入同步平移。布局细节偏离已登记 TE-D40「高度均衡」行。

## 验证请求(rc.10 重点)

- **输入行聚焦高度恒定**(rc.9 报告项①复验):在带 markdown 预览的问题里把高亮移到 "Type something."(输入行)再移回选项——对话框顶部与底部边缘应稳定不动(预览 pane 按设计隐藏/恢复,总高不变)。
- **页脚提示行贴底**(rc.9 报告项②复验):多题问卷切到 Submit 页——"Enter to select · … · Esc to cancel" 提示行应贴终端底边,其下不再有空行带;各题 tab / 输入行 / 备注编辑器打开时同样贴底。
- 其余验证面同 rc.9(去品牌化)与 rc.8(对话框高度稳定)。
