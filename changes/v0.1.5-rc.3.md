# v0.1.5-rc.3 (2026-09-27)

**Pre-release (pre-release channel)**: candidate for the `0.1.5` stable release. Content = `v0.1.5-rc.2` plus the full pre-stable review-fix batch below; at stable-release time this file's entries fold into `v0.1.5.md`. Upgrade: `rpi update --rc` (or `rpi update --all --rc` to also move the six lockstep extensions to `0.1.5-rc.3`).

This RC lands the outcome of a full pre-stable review pass (3 P0 / 6 P1 / a P2 sweep) plus an independent four-reviewer re-review of every fix — per-item detail in `changes/v0.1.5.md` § "Pre-stable review fixes".

## Fixed in this RC

- **WSL clipboard interop actually reaches PowerShell now** (P0): the write-path command runner dropped the collected stdout, so `wslpath -w` resolved to an empty Windows path and the `powershell.exe Set-Clipboard` leg never executed — real WSL (no Windows Terminal/WSLg) silently fell back to an unverified OSC 52 success. The runner now follows the upstream stdio policy (query calls return real stdout bytes; writer calls get no output pipe at all), and the writer's stdin moves off the UI thread so a wedged writer can no longer hang the copy path. Pinned by real-runner regressions including a fake-`wslpath` + recording-`powershell.exe` end-to-end chain.
- **Zero-TTL MCP servers keep their direct tools while connected** (#566, P0): the live-overlay cache entry carried the server's declared `ttlMs`, and `ttlMs == 0` entries are invalid by design — a connected zero-TTL server was skipped by the direct-tool surface. Overlay entries now strip the declared TTL exactly like the upstream overlay; regression-tested.
- **The release-notes single source of truth carries the release's largest BREAKING change** (P0): `changes/v0.1.5.md` now documents **V15-06 mid-conversation system messages** (`TranscriptContext`; migration notes for native plugin authors — the `Provider`/`StreamFn` trait narrowing and the `addedToolNames` removal) and the **V15-10** entries (the new `retry.maxAgentDelayMs` setting, compaction cancellation race closures, the EventStream regression suite); `CHANGELOG.md`'s v0.1.5 section is English end to end and mirrors the additions.
- **RPC `bash` runs the `user_bash` extension interception** with the same fail-closed contract as the interactive `!` path (all three arms pinned by an RPC-harness test), and **`mcp({ connect })`/`mcp({ search })` report `addedToolNames` at the tool-result top level** like the upstream adapter (e2e-pinned).
- **Review repair batch** (each with a regression test unless noted): the encrypted-file OAuth key decoder fails closed on multi-byte UTF-8 (no panic); macOS Local Network Privacy diagnostics match the real Rust io error texts; the #536 broker-before-grant order is pinned; dead DCR registrations are cleared from the store behind the URL-scoped `getAuthForUrl` visibility rule; `oauth.clientMetadataUrl` interpolates env vars and trims; `ask_user_question` multi-select answers strip control characters; the post-login default models match the regenerated catalog (zai/zai-coding-cn/cerebras/xai/baseten/qwen-token-plan-individual, all pinned against the catalog); the todo reducer compares JSON numbers numerically (`1` vs `1.0` is a no-op again); `agent_capabilities` reports real `executable`/`restrictedCount`/`restrictionSources` under a #2338 ceiling (and the capability listing partitions restricted agents); the Anthropic beta set rides the `anthropic-beta` header only; the wasm SDK's `unsubscribe` releases the state lock before the `off` host call; the subagents skill docs no longer teach the removed `fallbackModels` (asset-scan-pinned); the subagents `toolBudget` support surface is disclosed in the release notes (call-level honored; frontmatter/agentOverrides not wired).
