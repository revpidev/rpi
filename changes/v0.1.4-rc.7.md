# v0.1.4-rc.7(2026-09-12)

**预发布(pre-release channel)**:`0.1.4` 正式版候选第七轮。本轮 = **rc 窗口插件安装解锁**——`rpi install --rc` 通道选择器(V14-19 增补 R6.7,响应 rc.6 实测 `rpi install rpiv-ask-user-question` 报 `No installable version (available: 0.1.4-rc.6)`:该插件 registry 索引在 0.1.4 stable 前仅有预发布条目,而 install 此前恒 stable 通道)。基线内容与 `changes/v0.1.4.md` 一致;正式版发布时各 rc 文件条目并入 `v0.1.4.md`。安装/升级:已装 rpi 用户 `rpi update --rc`(或 `rpi update --all --rc` 同步扩展到 `0.1.4-rc.7`);官方脚本强装 `RPI_GITHUB_API_URL=https://api.github.com/repos/revpidev/rpi/releases/tags/v0.1.4-rc.7`。

## 相对 rc.6 的增量

- **`rpi install <name> --rc`**(R6.7):registry 源安装按 RC 通道解析(仅取预发布,与 `rpi update --extensions --rc` 同源;`rpiAbi`/`minHostVersion` 预检全 semver 预发布感知);不带旗标恒 stable(零回归);`remove`/`list` 拒绝该旗标;`npm:`/`git:`/本地路径源不受影响。**用法:`rpi install rpiv-ask-user-question --rc`**(rc 宿主上安装 rc 版新插件;注意先 `rpi update --rc` 到 rc.7——rc.6 二进制无此旗标)。

## 验证请求(rc.7 重点)

- **新插件安装与对话框**(rc.6 验证请求的解锁项):`rpi update --rc` 到 rc.7 → `rpi install rpiv-ask-user-question --rc` → 重启会话 → 让模型在需求不清时触发 ask_user_question(或直接要求它使用该工具):底部 tabbed overlay 问卷渲染、Tab/方向键/多选/备注、Ctrl+G 外部编辑器、折叠重开、Submit 结果信封。
- **通道回归**:无旗标 `rpi install <已stable插件>` 行为不变;`rpi update --all --rc` 扩展 lockstep 到 rc.7。
- 其余验证面同 rc.6(见 `changes/v0.1.4-rc.6.md`)。
