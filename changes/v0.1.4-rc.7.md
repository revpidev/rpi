# v0.1.4-rc.7 (2026-09-12)

**Pre-release (pre-release channel)**: round seven of the `0.1.4` stable candidates. This round = **unlocking plugin installs during the rc window** — the `rpi install --rc` channel selector (V14-19 addendum R6.7, answering the rc.6 field report that `rpi install rpiv-ask-user-question` failed with `No installable version (available: 0.1.4-rc.6)`: the plugin's registry index carries only pre-release entries before the 0.1.4 stable, while install was hardcoded to the stable channel). The baseline content matches `changes/v0.1.4.md`; at stable-release time each rc file's entries fold into `v0.1.4.md`. Install/upgrade: existing rpi users run `rpi update --rc` (or `rpi update --all --rc` to sync extensions to `0.1.4-rc.7`); force-install via the official script with `RPI_GITHUB_API_URL=https://api.github.com/repos/revpidev/rpi/releases/tags/v0.1.4-rc.7`.

## Increments relative to rc.6

- **`rpi install <name> --rc`** (R6.7): registry-source installs resolve on the RC channel (pre-releases only, sharing the source with `rpi update --extensions --rc`; `rpiAbi`/`minHostVersion` pre-checks fully semver pre-release aware); without the flag it's always stable (zero regression); `remove`/`list` reject the flag; `npm:`/`git:`/local-path sources are unaffected. **Usage: `rpi install rpiv-ask-user-question --rc`** (installing the rc version of the new plugin on an rc host; note: first `rpi update --rc` to rc.7 — the rc.6 binary lacks the flag).
