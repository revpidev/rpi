# v0.1.4-rc.1(2026-09-08)

**预发布（pre-release channel）**：`0.1.4` 正式版候选，先于正式版供验证。内容与 `changes/v0.1.4.md` 一致（上游追平 v0.85.0+ 主线 + M5 收口），叠加本文件新增的 RC 更新通道；正式版发布时本文件条目并入 `v0.1.4.md`。安装方式：已装 rpi 的用户运行 `rpi update --rc`（或 `rpi update --all --rc` 同步更新四款 lockstep 扩展到 `0.1.4-rc.1`）；install.sh 不提供 RC（`releases/latest` 保持 stable）。

## 本 RC 新增（不随上游追平主线、随 rc.1 首次出现）

- **RC 更新通道**（V14-19，rpi 自有需求）：`rpi update --rc` 更新本体到最新 RC、`rpi update --extensions --rc` 更新扩展到最新 RC 版本，不带 `--rc` 恒为 stable；通道是单次命令旗标不持久化；预发布构建的启动版本检查自动改探 RC 端点（横幅标注 pre-release，指引 `rpi update --rc`）；rc 构建切回正式版直接 `rpi update`（无旗标）。发版流程与版本号规范（`<stable>-rc.<N>`）见仓库 `RELEASING.md` RC 小节。

## 验证请求（RC 目的）

- 六目标自更新路径（`rpi update --rc` 下载 + sha256 校验 + 原子替换；Windows 为手动替换指引）
- `rpi update --extensions --rc`：四款 lockstep 扩展（subagents / mcp-adapter / smart-fetch / statusline）从 0.1.3 → 0.1.4-rc.1；不带 `--rc` 时保持 0.1.3（stable 通道过滤预发布）
- 上游追平 v0.85.0+ 主线行为面（18 任务清单见 `changes/v0.1.4.md`）

已知边界：RC 端点（`https://revpi.dev/api/latest-rc-version.json`）在 Release 资产就位后生效；自建镜像用户需同目录提供该文件。
