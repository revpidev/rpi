# v0.1.6-rc.1 (2026-10-05)

**Pre-release (pre-release channel)**: candidate for the `0.1.6` stable
release, published ahead of it for verification. Content matches
`changes/v0.1.6.md` (the upstream-parity v1.0.0 main line, the codemode /
built-in MCP landing, the theme / auth / virtual-model / fixes family, the
rpi-own mode + usage framework, and the eight-plugin lockstep line); at
stable-release time this file's entries fold into `v0.1.6.md`. Install:
existing rpi users run `rpi update --rc` (or `rpi update --all --rc` to also
update the eight lockstep extensions to `0.1.6-rc.1`); install.sh does not
serve RCs (`releases/latest` stays stable). The two new first-party plugins
install from the RC channel with `rpi install rpi-plan-mode --rc` and
`rpi install rpi-usage --rc` (they have no stable release yet — without
`--rc` the bare names resolve to nothing). The renamed
`rpi-ask-user-question` / `rpi-todo` follow the clean-switch migration: the
former names and install paths are retired (no alias, no redirect — remove
the old install and reinstall).

## New in this RC (first release of the v0.1.6 window)

- **Upstream parity to v1.0.0** (ADR-0035; 46 commits on top of v0.99.2):
  fullscreen TUI default, the codemode description slimming + `guard()`
  error recovery and `models.generateImages()`, the built-in MCP OAuth
  hardening and credential-key migration, copy-code and Radius sign-in,
  `--provider` fail-fast, the TUI fix family, and the v1.0.0 polish
  surfaces. Per-domain highlights in `changes/v0.1.6.md`.
- **Built-in codemode + tool search** (V16-07): the `codemode` script tool
  (QuickJS-in-WASM sandbox, script-side `tools.*` / `models.*` / `store()`,
  `// @options` budgets) and the BM25 `tool_search` tool, plus structured
  bash results (additive `outputSchema` / `structuredContent`).
- **Built-in MCP extension** (V16-08): `mcp.json` servers (stdio /
  streamable HTTP), exposure classes, resource tools, `/mcp` and
  `rpi mcp`, project trust, and OAuth 2.1 with the hardened v1.0.0
  credential layout.
- **Theme system + fullscreen default** (V16-10): `theme` defaults to
  `system` with OKHSL-derived dark/light themes, the single-pass terminal
  color query, `tuiMode` defaults to `fullscreen`, wheel acceleration,
  `quietStartup`, and the TUI fixes family.
- **Authentication** (V16-11): Sign in with ChatGPT (+ `deviceId`), the
  shared OAuth callback server, Anthropic WIF / copy-code login, and the
  Radius `/login` entry with one-click MCP configuration.
- **Virtual models** (V16-12, experimental): `registerVirtualModel()` with
  per-request routing, session-branch router state, and routed display.
- **rpi-own host surfaces** (V16-05, V16-13, V16-14): permission modes
  (`Shift+Tab`, `⏸ plan`, `getMode`/`setMode` + `mode_change`), the
  scripted usage-provider framework (`ctx.usage.*`), `builtin:<name>`
  extension governance + settings/RPC dispositions, and the session-scoped
  tool-exposure overrides.
- **Two new first-party plugins** (TE43/TE44): `rpi-plan-mode` (`/plan`,
  read-only exposure boundary, `write_plan`, approval dialog) and
  `rpi-usage` (`/usage`, four built-in provider scripts, footer status
  line) — native carrier only, registered under the `rpi-` prefix.
- **Plugin rebases + rename** (TE42/TE45/TE46, ADR-0033):
  `rpi-ask-user-question` / `rpi-todo` renamed (clean switch);
  `rpi-subagents` rebased to v0.74.0; `rpi-mcp-adapter` rebased to v4.0.0
  and now an optional replacement for the built-in MCP extension sharing
  the same `mcp.json` layout.
- **Breaking changes**: session format / canonical context (V16-03,
  `context_edit`), the extension event surface and tool-orchestration ABI
  (V16-06, additive but boundary-visible), codemode `typeof` probing
  (V16-07), the terminal-color query replacement and `tuiMode` default
  (V16-10), MCP tool naming `-` → `_` (V16-08), and the plugin rename —
  full list in `changes/v0.1.6.md` (§Breaking changes).

## Verification requests (the point of the RC)

- Self-update path on all six targets (`rpi update --rc` download + sha256
  verification + atomic replacement; Windows gets manual-replacement
  instructions).
- `rpi update --extensions --rc`: the **eight** lockstep extensions going
  `0.1.5` → `0.1.6-rc.1` — including the **first-ever release of
  `rpi-plan-mode` and `rpi-usage`** (`rpi install <name> --rc` for a fresh
  install); without `--rc` the six previously-shipped extensions stay at
  `0.1.5` and the two new ones are not resolvable (the stable channel
  filters prereleases).
- The guest-facing surfaces of the window: codemode / tool_search /
  built-in MCP, the theme system + fullscreen default, Sign in with
  ChatGPT / Anthropic WIF, virtual models, plan mode + `/usage`, and the
  plugin renames/rebases — the task list is in `changes/v0.1.6.md`.

Known boundary: the RC endpoint (`https://revpi.dev/api/latest-rc-version.json`)
goes live once the Release assets are in place; self-hosted mirrors must
provide the file in the same directory.
