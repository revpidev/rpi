# v0.1.0 (2026-08-15)

Initial release.

## First shipping scope

- **Three modes**: interactive TUI / JSON-RPC (server) / print (single-shot output).
- **Model runtime** (rpi-ai): multi-provider access with message types and streaming semantics aligned to upstream.
- **Agent sessions**: session persistence and context compaction.
- **Resource system**: skills / prompt templates / themes.
- **Built-in tools**: bash / read / edit / write.
- **Extension host**: wasm sandbox (L1) + native L0 plugin ABI.
