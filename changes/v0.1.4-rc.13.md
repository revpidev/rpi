# v0.1.4-rc.13 (2026-09-14)

**Pre-release (pre-release channel)**: round thirteen of the `0.1.4` stable candidates. This round = **the model catalog refresh to the 2026-09-14 snapshot** (catalog-only, the behavioral pin untouched, deviation D-101). Install/upgrade: existing rpi users run `rpi update --rc` (or `rpi update --all --rc` to sync extensions to `0.1.4-rc.13`); force-install via the official script with `RPI_GITHUB_API_URL=https://api.github.com/repos/revpidev/rpi/releases/tags/v0.1.4-rc.13`.

## Increments relative to rc.12

- **Built-in chat model catalog refresh** (39 files, 1354 → **1397** models, +79/−36): the upstream generator ran in a one-off upstream worktree (`external/pi` origin/main @ `71dca871b`) pulling the models.dev/OpenRouter/NVIDIA/Vercel snapshots (2026-09-14), vendored via `scripts/refresh-model-catalog.sh` (every file sha256-checked against the manifest). Highlights: Bedrock regional families +34 (GPT-6 Astra/Grok-4.6/Gemma-4/Nova regional prefixes in full); OpenAI Codex retiring `gpt-5.4`/`gpt-5.4-mini`; DeepSeek merging `v4-flash(-vision-exp)` into `deepseek-flash`; moonshotai (CN/global) retiring the old kimi-k2 preview families; Fireworks +3 with compat updates (`allowEmptySignature`/`supportsToolReferences` baked in); Copilot `gpt-6-astra` rerouted to the Responses API; OpenRouter 366→379 (bulk `:batch` variants + the GPT Luna/Sol/Terra/Astra alias families).
- **Image model catalog refresh** (50 → **54**): `microsoft/mai-image-2.6`, `mai-image-2.6-flash`, `openai/gpt-image-2.5-flare`, and `gpt-image-2.5-sunburst` added, with field-level updates to models.dev display names/prices; the manual transcription surface per D-037 was fully rewritten and a **vendored reference TS** added (`crates/rpi-ai/src/images/image-models.generated.ts`) — the parity tests now read that file (following the model_catalog.rs V14-09 precedent of "the pinned submodule's generated data is deliberately stale after a catalog-only refresh", removing the hard dependency on a submodule checkout).
- **Zero behavioral change**: adapter behavior/request assembly/compat consumption logic untouched; the upstream behavioral pin stays `9841914` (UPSTREAM.md); the catalog-only refresh is registered as deviation **D-101** (converging naturally once v0.1.5 raises the pin to ≥`71dca871b`).
- **Test assertions updated to the catalog ground truth**: totals 1397 (roundtrip/generated) / 54 (image parity); per-provider counts (deepseek 3→2, fireworks 20→23, huggingface 71→75, together 21→22, baseten 20→21); `gpt-5.4` assertions migrated to `gpt-5.5` (following upstream 2e6fe2f98); the Fireworks kimi-k2p6 compat keys completed; generatedAt pinned to `2026-09-14T02:27:28.134Z`. Full gates zero failures (6280 cases).
- **rpi-pages remote catalog sync**: `api/models/providers/*.json` regenerated from the vendored data (data plane only; the stable/RC endpoints untouched).
