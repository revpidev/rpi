# v0.1.4-rc.6(2026-09-11)

**预发布(pre-release channel)**:`0.1.4` 正式版候选第六轮。本轮 = **v0.1.4 增补线全量首次进入 RC 通道**(M6:插件重定基 pin 原子切换 + 交互式自定义 UI ABI + 新插件 rpiv-ask-user-question + `ctx.sessionEntries`)+ M7 收口销项(五项独立跟踪项测试/harness 加固)。基线内容与 `changes/v0.1.4.md` 一致;正式版发布时各 rc 文件条目并入 `v0.1.4.md`。安装/升级:已装 rpi 用户 `rpi update --rc`(或 `rpi update --all --rc` 同步扩展到 `0.1.4-rc.6`);官方脚本强装 `RPI_GITHUB_API_URL=https://api.github.com/repos/revpidev/rpi/releases/tags/v0.1.4-rc.6`。

## 相对 rc.5 的增量(全部来自增补线 M6 + M7 收口)

### 插件重定基(pin 原子切换,ADR-0025)

- **双插件基线升级**:`pi-subagents` v0.48.0(`56f97234`)→ **v0.66.0**(`0fc0eebb`,568 commits)、`pi-mcp-adapter` v2.24.0(`3d953f90`)→ **v2.32.1**(`10a45367`,90 commits);`smart-fetch`/`pi` 不动。subagents:事件流与 fallback/重放守卫、发现健壮性(诊断出口/剪枝/符号链接)、worktree 完整性与终态分类、写失败重试与通知 v2、启动契约与工具面交集门、模型降级、steer 门与 Fleet 稳定排序、配置面新键(`subagents.maxThinking`/`defaultProvider`/`agentScanDirs` 等)。mcp:命令接线(`/mcp`、`/mcp-auth`)、审批作用域与持久化、退避可见性、ttlMs 缓存、OAuth 401 重注册、生命周期/诊断/渲染、性能加固。
- **BREAKING:mcp direct 工具命名**(R7.2.4):server 级前缀解析与跨 server 碰撞抑制、include/exclude 与审批同源;已配置 direct tools 的用户请 review `mcp.json`(指南:`toolPrefix:"none"`);详细条目见 `changes/v0.1.4.md` 插件重定基节。
- **语义变更:子代理上下文**(ADR-0026):`defaultContext: fork` 不可用时**降级 fresh + 警告**(不再 fail-fast);子代理**默认不继承全局上下文**(宿主 `RPI_NO_GLOBAL_CONTEXT` 开关);迁移指引见 `changes/v0.1.4.md`。

### 交互式自定义 UI ABI(ADR-0024/0027,native + wasm 双载体)

- 扩展可挂载交互组件的 7 个 additive `ui.*` host-call(挂载/轮询/渲染/隐藏/唤醒/卸载/外部编辑器),capability `ui`,不升 `rpiAbi`;overlay 挂载、行帧合成与光标、`tick`/`wake`、隐藏态、清理矩阵(工具中止/会话关闭/重载/扩展卸载/生命周期上限/guest trap)、wasm fuel 预算与限额 fail-visible;`ui.editExternal` 外部编辑器链(复用 `Ctrl+G` 流程)。
- **`ctx.sessionEntries` additive host-call**(ADR-0027):活动分支 custom entries 只读;mcp 审批恢复已迁移消费(ABI 优先 + JSONL 旧数据降级)。

### 新插件:rpiv-ask-user-question(TE28–TE32)

- 模型在需求不清时发起 1–4 题问卷(2–4 选项/多选/markdown 预览/备注),交互终端经 UI ABI 渲染底部 tabbed overlay(键位/信封与上游逐字节对拍,视觉为 rpi 自有设计 TE-D40);RPC/ACP 宿主降级宿主原生 select/input walker;非交互运行自动摘除。配置 `~/.config/rpiv-ask-user-question/config.json`(沿用上游,TE-D39),9 locale 全量。**随宿主 lockstep 发布 `.rpix`**(版本号 = 宿主版本)。

### M7 收口销项(测试/harness 面,零产品行为变更)

- smart-fetch parity 回放临时目录卫生(修复每次测试向默认临时目录泄漏文件、累计后门禁必红的问题);conformance 证据链归一化稳定排序(消除复跑 churn);model_runtime login 用例确定性化(负载下偶发失败根治);offline 环境变量测试竞态共享锁(13 处敏感测试固定,三轮复核问题闭环至零未处置);fanout 安装配置错误在消耗 spawn 预算**之前**报错(不再以预算耗尽掩盖根因)。
