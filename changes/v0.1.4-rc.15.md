# v0.1.4-rc.15(2026-09-16)

**预发布(pre-release channel)**:`0.1.4` 正式版候选第十五轮。本轮 = **statusline `live_output` 原始材料透传**(#45)。安装/升级:已装 rpi 用户 `rpi update --rc`(或 `rpi update --all --rc` 同步扩展到 `0.1.4-rc.15`);官方脚本强装 `RPI_GITHUB_API_URL=https://api.github.com/repos/revpidev/rpi/releases/tags/v0.1.4-rc.15`。

## 相对 rc.14 的增量

- **statusline 脚本侧语言感知 token 统计的原材料透传**(#45;`rpi-statusline` 插件,PR #49):`rpi.live_output` 此前只给聚合字符数,脚本被迫用单一 chars/token 因子换算——中文(~1.0–1.3 chars/token)与英文/代码(~3.5–8)双向偏差,校准因子还随最近一条消息的语言漂移。调研确认宿主早已把原材料送进扩展事件:`message_update` 载荷原样携带累积 partial(全文文本块 + `usage`;OpenAI 兼容流 chunk usage 与 Anthropic `message_delta` 的运行总量都落在 `/message/usage/output`),插件此前只数了字符即丢弃。修复为插件内留存并透传,`live_output` 新增 6 个 additive 字段:`output_tokens`(流中 provider 累积 output tokens,仅 >0 时出现、后续沉默不回写,`message_end` 后仍由 `output_tokens_exact` 收尾)、`text`/`thinking`/`toolcall`(当前消息各类 delta 的**累积原文**,`message_start` 重置、`message_end` 冻结,与 `*_chars` 恒等不变式测试钉死)、`decode_started_at_ms`(本消息首个 delta 的墙钟 epoch ms,TTFT 排除锚点,一次设定不随 tick 重基)、`message_id`(插件本地单调 id,逐消息变化,无状态脚本检测换消息)。选型:累积原文而非 per-tick delta——脚本是无状态进程逐次重跑(V13-10 §1.2 分层),delta-only 会迫使脚本跨调用持久化状态拼文本,速率已有 `delta_chars`/`delta_ms` 覆盖;native 只测量不换算红线不变(语言感知估算完全在脚本侧,可自由做 CJK/Latin script split 或换真 tokenizer);`peek_fingerprint` 纳入流式 usage 与消息序号(reasoning token 可无字符前进、冻结态换消息自愈)。宿主/ABI/订阅集/JSON-RPC 线协议零改动;原 8 字段逐字节不变;未配置 `liveTokens` 行为与 TE12 完全一致。已知良性差异(相对 `message_end` 权威 content):无签名、无块结构(多块拼接)、redacted thinking 缺席——不影响 token 估算。
- **门禁**:`cargo test -p rpi-ext-statusline` 52 单测 + 3 集成二进制全绿(新增:原始文本留存与 `message_id` 逐消息变化、流中 usage 0-guard 锁存、decode 锚点首 delta 一次设定、fingerprint 随流式 usage/消息序号移动、载荷新字段形状与省略矩阵、跨 carrier-seam 的流中 usage/原文/锚点/冻结值断言);clippy/fmt 干净。

## 验证请求(rc.15 重点)

- 配置 `statusLine.liveTokens` + 自定义 token 速率脚本:中文/英文流式各一轮,`rpi.live_output` 的 `text` 原文与 `output_tokens` 透传正确;有流中 usage 的 provider(OpenAI 兼容/Anthropic)速率应即刻精确(无需估算),其余 provider 用原文做 script split 估算;`message_end` 后 `output_tokens_exact` 收尾一致;`decode_started_at_ms` 锚定的速率不应再随 1Hz 刷新抖动。
- 未配置 `liveTokens` 的用户:statusline 行为与 rc.14 完全一致(零变化回归)。
