# v0.1.6-rc.2 (2026-10-06)

**Pre-release (pre-release channel)**: candidate for the `0.1.6` stable
release. Content = `v0.1.6-rc.1` plus the pre-stable review hardening below
(two full review rounds on the rc.1 surface); at stable-release time this
file's entries fold into `v0.1.6.md`. Upgrade: `rpi update --rc` (or
`rpi update --all --rc` to also move the eight lockstep extensions to
`0.1.6-rc.2`); `install.sh` does not serve RCs (`releases/latest` stays
stable). The two new first-party plugins install from the RC channel with
`rpi install rpi-plan-mode --rc` and `rpi install rpi-usage --rc`.

## Fixed in this RC (pre-stable review hardening)

Two full review rounds on the rc.1 surface; per-domain detail and the
per-fix regression notes are in `changes/v0.1.6.md` §Review hardening.
Highlights:

- **Codemode**: execution output is capped at 16 MiB with an explicit
  notice; cancel/Esc settles scripts that never settle, and a script that
  catches the QuickJS interrupt cannot outlive its timeout; store writes
  persist even without a return value; JSON depth (1024) and trailing
  garbage are enforced; the `close()` wakeup race family is closed.
- **MCP**: numeric ids are matched by value for every server-echoed id that
  indexes a map (responses, progress tokens, cancellation); the built-in
  OAuth store keeps rotated refresh tokens, refuses to overwrite a corrupt
  or unreadable store, writes atomically (0600 + parent sync, lock dir
  0700), distinguishes lock contention from local setup errors, and
  reports a sign-in whose credentials could not be persisted; the adapter
  drops server-wide session grants on branch navigation, consults the
  broker before the server grant, fails closed on non-array `approveTools`
  values (including the still-deferred `"destructive"`), and explains the
  server-wide choice in the approval dialog.
- **Plan mode**: a transient host-call failure (`getMode`/`getAllTools`/
  `getActiveTools`) keeps the hidden boundary and retries; a failed exit
  cleanup notifies once per entry and retries; `planDir` expands `~/`;
  `/plan edit` writes atomically; per-session state drops on
  `session_shutdown`.
- **Subagents**: every task/step agent resolves before any side effect
  (foreground and background, with batch errors keeping their composition
  mode); per-agent `modelScope.agents.<name>` rules fail closed without a
  parent model and are enforced by their own `enforce`; inherited Git
  routing variables are stripped from children; untrusted projects pass
  `--no-approve`.
- **Extensions / rendering**: unknown tool `exposure` values are
  `invalidRequest`; native host calls on an unloaded plugin answer a
  stale-context error; re-entrant `executeTool`/virtual-model dispatches
  fail closed, and events for an extension blocked in a synchronous host
  call are skipped (D-105); extension `renderResult` hooks receive the
  tool result's `isError`, so errored cards (a failed subagent preflight,
  a failed `write_plan`) render as failures on both the live update and
  the transcript-rebuild paths.
- **Usage providers**: the host's enforced timeout is injected into the
  provider scripts; `/usage` while disabled clears a stale footer line;
  `auth.json` `${VAR}` resolves like `$VAR`; a Windows `.cmd` launcher
  write failure is a hard error.
- **Themes / CLI**: non-ASCII theme colors no longer panic; unknown theme
  keys are ignored like upstream; `system` themes keep their styling in
  `/export`; script children are killed on drop, and Windows kills use the
  full process tree.
