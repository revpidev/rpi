# v0.1.4-rc.2(2026-09-08)

**预发布（pre-release channel）**：`0.1.4` 正式版候选第二轮，修复 rc.1 验证发现的两处缺陷。基线内容与 `changes/v0.1.4.md` 一致；正式版发布时各 rc 文件条目并入 `v0.1.4.md`。安装/升级：已装 rpi 用户 `rpi update --rc`（或 `rpi update --all --rc` 同步扩展到 `0.1.4-rc.2`）；官方脚本强装 `RPI_GITHUB_API_URL=https://api.github.com/repos/revpidev/rpi/releases/tags/v0.1.4-rc.2`。

## 相对 rc.1 的修复（rc.1 验证发现，rpi#22 / rpi#23）

- **editor 上方恒留 1 行间隔**（rpi#22）：流式输出内容与内嵌 editor 顶边框「⠋ Working」之间此前没有间隔——上游 `abb1775ff`（PR #850）给 `widgetContainerAbove` 引入的恒驻 leading `Spacer(1)` 从未随 setWidget 移植，V14-17 内嵌化后暴露；修复为 widgets_above 构造时播种永久 Spacer（`widgets_below` 不加，对齐上游 spacerWhenEmpty=false）。
- **移除全屏鼠标分发路径的两处 DBG 调试打印**（rpi#23，V14-14 移植遗留）：已有会话切全屏后右下角多行 `[DBG layout dispatch]`/`[DBG selection press]` 输出、滚动条区域界面异常、进度条被冲、输入区被覆写——raw mode + alt screen 下 stderr 直写绕过 TUI 游标模型落在光标处，且 diff 渲染不重绘被覆写行使损伤持久化；修复为删除两处调试行 + rpi-tui 库 crate `deny(clippy::print_stdout/print_stderr/dbg_macro)` 结构性防护（测试豁免）+ 双层回归测试（rpi 层触发序列 + rpi-tui 层 VT 屏幕级逐行断言：热切换 + 内容超视口 + 滚动条/dock 干净、鼠标风暴前后屏幕逐字节不变）。

- 其余验证面同 rc.1（见 `changes/v0.1.4-rc.1.md`）
