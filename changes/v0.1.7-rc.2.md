# v0.1.7-rc.2 (2026-10-18)

**Pre-release (pre-release channel)**: candidate for the `0.1.7` stable release. Content = `v0.1.7-rc.1` plus the pre-stable review hardening below; at stable-release time these entries fold into `changes/v0.1.7.md`. Upgrade: `rpi update --rc` (or `rpi update --all --rc` to also move the seven lockstep extensions to `0.1.7-rc.2`); `install.sh` does not serve RCs (`releases/latest` stays stable).

## Fixed in this RC (pre-stable review hardening)

- **Windows clipboard paste works for text and file drops**: plain text reads through `Get-Clipboard -Raw` (UTF-8), and `FileDropList` emits `FileInfo.FullName` instead of PowerShell's table formatting. The read runs off the TUI thread, so slow PowerShell/xclip probes no longer freeze input; Linux text reads also fall back to `xsel`, and pasted images go to private `0600` temp files with random names.
- **Compaction-queue messages join the first run**: the flush now runs the prompt preflight, queues the remaining steer/follow-up messages, and then awaits the run, matching upstream `flushCompactionQueue`. Messages queued during compaction no longer wait for the next user input.
- **`/usage all` labels each provider**: TE50 removed the provider prefix from the footer text, so `all` now adds a `provider:` heading before each successful section.
- **Durable transaction cancellation is safe**: a cancelled SQLite transaction queues a `ROLLBACK` before releasing the access mutex; close paths reset their "done" flag on cancellation/failure; temp dirs/files are `0700`/`0600` and use random names.
- **MCP close state is terminal**: `close()` restores `Closed` after a setup that raced it, and a late client-close callback no longer overwrites it.
- **Tool patterns without `*` are anchored literals**: `tool_pattern_matches("aa", "aaa")` is false again, and the empty pattern only matches the empty value.
- **Test hardening**: the shared parity normalizer fixes `wall_time_seconds`; rpi-todo/rpi-plan-mode test directories use process-wide counters; the usage-provider timeout test no longer races the fast control fetch.
- **MSRV and dependencies**: the workspace requires Rust 1.95, CI compiles with that toolchain, and wasmtime 48.0.6 / rustls 0.23.46 / quinn-proto 0.11.18 close the RustSec findings (0 known vulnerabilities; six advisory warnings remain for unmaintained transitive crates).

## Known Issues

- **MCP OAuth issuer binding is deferred to v0.1.8** ([GHSA-6qxp-vccf-f47h](https://github.com/advisories/GHSA-6qxp-vccf-f47h)): credentials written by earlier versions without the stored authorization-server discovery state re-discover the authorization server from the MCP server on refresh; the issuer binding itself is not yet enforced.
