# v0.1.4-rc.8(2026-09-12)

**预发布(pre-release channel)**:`0.1.4` 正式版候选第八轮。本轮 = **ask-user-question 对话框高度稳定修复**(rc.7 实机验证报告:切换选项时预览高度不同 → 询问界面总高跳变)。基线内容与 `changes/v0.1.4.md` 一致;正式版发布时各 rc 文件条目并入 `v0.1.4.md`。安装/升级:已装 rpi 用户 `rpi update --rc`(或 `rpi update --all --rc` 同步扩展到 `0.1.4-rc.8`);官方脚本强装 `RPI_GITHUB_API_URL=https://api.github.com/repos/revpidev/rpi/releases/tags/v0.1.4-rc.8`。

## 相对 rc.7 的增量

- **对话框高度稳定**:切换选项(预览渲染高度不同)或切 tab 时,询问界面总高恒定——移植上游 rpiv-mono 的 worst-case body height + 残差垫行机制(跨全部题目/选项取最大 body 高,较矮的当前内容尾部垫空行到一致足迹;内容超出终端高度时走既有滚动窗口,不垫行)。注:上游 rpiv-ask-user-question 同版本即此行为,rpi 此前漏移植该机制(对拍面均为单状态帧,跨选项高度不变量不在覆盖内,实机验证暴露)。

## 验证请求(rc.8 重点)

- **对话框高度稳定**(rc.7 报告项复验):在带 markdown 预览的问题里用 ↑/↓ 在高度不同的选项间切换——询问界面顶部边缘应稳定不动;切 tab / 到 Submit 页同样稳定。
- 其余验证面同 rc.7(新插件安装 `rpi install rpiv-ask-user-question --rc` 与对话框功能)与 rc.6。
