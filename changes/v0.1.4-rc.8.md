# v0.1.4-rc.8 (2026-09-12)

**Pre-release (pre-release channel)**: round eight of the `0.1.4` stable candidates. This round = **the ask-user-question dialog height-stability fix** (rc.7 field report: switching between options with differently sized previews made the questionnaire's total height jump). The baseline content matches `changes/v0.1.4.md`; at stable-release time each rc file's entries fold into `v0.1.4.md`. Install/upgrade: existing rpi users run `rpi update --rc` (or `rpi update --all --rc` to sync extensions to `0.1.4-rc.8`); force-install via the official script with `RPI_GITHUB_API_URL=https://api.github.com/repos/revpidev/rpi/releases/tags/v0.1.4-rc.8`.

## Increments relative to rc.7

- **Dialog height stability**: switching options (with differently sized previews) or tabs keeps the questionnaire's total height constant — porting upstream rpiv-mono's worst-case body height + residual spacer mechanism (take the maximum body height across all questions/options and pad the shorter current content's tail with blank lines to a consistent footprint; content exceeding the terminal height goes through the existing scrolling window, no padding). Note: upstream rpiv-ask-user-question at the same version already behaved this way; rpi had failed to port the mechanism (the parity surface only covered single-state frames, and the cross-option height invariant wasn't in scope — exposed by field verification).

## Verification requests (rc.8 focus)

- **Dialog height stability** (re-checking the rc.7 report): in a question with a markdown preview, use ↑/↓ to switch between options of different heights — the questionnaire's top edge should stay put; switching tabs / going to the Submit page likewise stable.
- Remaining verification surface as in rc.7 (new-plugin install via `rpi install rpiv-ask-user-question --rc` and dialog functionality) and rc.6.
