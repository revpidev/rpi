resetpi.com

Product endpoints for the pir coding agent (defaults since ADR-0009; every endpoint is still overridable via PIR_* env vars or settings.json).

EndpointPurpose
/api/models/providers/{id}Remote model catalog overlay (38 built-in providers, ETag/304 revalidation)
/api/latest-versionVersion check: {"version","packageName","note"}
/api/report-installInstall telemetry ping (GET ?version=)
/session/#{gistId}Share viewer (redirects to the GitHub gist)
/changelogChangelog page shown in the update banner

Source: deploy/resetpi/ in the pir repository. Regenerate with python3 deploy/resetpi/scripts/generate-site.py, deploy with npx wrangler pages deploy deploy/resetpi --project-name=resetpi.
